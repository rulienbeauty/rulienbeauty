## GitHub Pages steps
1. Go to https://github.com and create a free account.
2. Click New repository.
3. Repository name: rulienbeauty-site
4. Choose Public.
5. Click Create repository.
6. Upload all files in this folder to the repository root.
7. Go to Settings > Pages.
8. Source: Deploy from a branch.
9. Branch: main.
10. Folder: /root.
11. Click Save.
12. Your free test URL will look like:
   https://YOUR-USERNAME.github.io/rulienbeauty-site/
